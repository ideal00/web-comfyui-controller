# Easy Panel 2.3.5

加入自定义面板配色，默认使用柔和灰，配套 Android **1.4.7**。

- 从顶部“更多 → 面板配色”或左侧“界面”打开；桌面和手机都可使用。
- 提供柔和灰、暖灰夜间、浅色鼠尾草、暖色纸张以及原蓝色；可自定义页面背景、卡片、输入框、文字和强调色。
- 即时预览并自动保存到当前浏览器，刷新前恢复；文字与背景太接近时提示调整，保存失败时给出说明。
- 常用卡片、按钮、输入框、候选区和弹窗跟随配色，图片及画布内容保持原样。包含此前的画风参考图和手机操作修复。

## 升级与验证

维护者本地页面已更新，刷新即可使用。其他电脑下载 Core，备份个人数据后更新。Android 继续使用 1.4.7；配色在不同浏览器和地址分别保存。

235 项 JavaScript 回归测试通过，覆盖配色恢复、原配色还原、输入校验、保存不可用及预设对比度。桌面和 390px 手机模式浏览器验证入口、自定义颜色、深浅预设、刷新恢复与弹窗布局；未进行 Android 真机验收，未提交生成任务。
