# Easy Panel 2.3.6

改进模型路径复制、局域网复制反馈和配色保存提示，配套 Android **1.4.7**。

- 基础模型下方增加“复制路径”，复制它在模型目录中的路径和文件名，适用于长名称及多级文件夹。
- LoRA 同名 TXT 复制支持 Android 剪贴板桥接；浏览器剪贴板被拒绝时尝试备用方式，失败会明确提示手动复制，恢复原控件焦点。
- 配色弹窗区分默认、已保存和浏览器禁止保存的状态；关闭再打开不会把保存失败误报为成功，损坏的数据会恢复默认。
- 保留自定义配色、LoRA 画风参考图和此前的手机操作修复。

## 更新

下载 Core，备份个人数据后更新。Android 继续使用 1.4.7；电脑面板更新后刷新高级面板即可。安装包不包含个人模型、LoRA 备忘或测试图片。

## 验证

240 项 JavaScript 回归测试通过，覆盖剪贴板拒绝、备用复制失败、Android 桥接、焦点恢复和配色弹窗重新打开。独立静态预览使用示例模型检查桌面与 390px 手机布局及复制按钮；未连接生产 ComfyUI，未提交生成任务，未进行 Android 真机验收。
