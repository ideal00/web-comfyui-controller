# 自由组合界面整理

- 分区卡片按自身高度展开，收起项不被相邻编辑器撑高。
- 用保留、追加、替换、锁定标记显示分区状态。
- 每区增加个人预设搜索，覆盖名称、英文正文和使用说明；无匹配时保留草稿。
- 选中预设后显示使用说明，组合预设仍只取当前分区。
- 应用前显示变更数量及各分区完整的应用前后内容。
- 底部应用、保存按钮保持可见；窄屏导航可横向滚动。
- 统一输入框、焦点框、边框与深色背景。运行目录与安装器副本同步，资源版本升级到 v3。
