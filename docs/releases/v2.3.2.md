# Easy Panel 2.3.2

修复 Android 高级面板候选能显示、轻点却一直停在预览而无法填入的问题。有图、无图的分区预设与普通标签均使用同一操作方式；配套 Android **1.4.7**，无需新版 APK。

- **轻点候选直接填入**；长按约半秒查看参考图，松开不填入，再轻点可填入。
- 滑动只滚动；多指、取消触摸或候选刷新会取消当前手势，避免误选。
- 使用最初触摸的候选，避免键盘改变布局后点入其他行；屏蔽触摸后的模拟鼠标事件，避免重复写入或残留预览。
- 保留桌面鼠标悬停预览、键盘选择与 🖼 打开图库，并包含 2.3.1 的搜索等待修复。
- 同步教程、缓存版本、七个 ZIP 与 `SHA256SUMS.txt`。

## 升级

维护者当前本地目录已经更新，在 Android 高级面板右上角刷新，或返回后重新打开即可。其他电脑下载 `EasyPanel-Core-OneClick.zip`，备份个人数据后安装、重启面板并刷新网页；ComfyUI 无需因本次前端修复重启。

## 验证

211 项 JavaScript 回归通过，覆盖有图 / 无图预设与普通标签轻点、长按、滑动、取消、多指、候选刷新、布局变化和模拟鼠标事件。实际页面用触摸事件模拟验证有图 / 无图预设补全与添加标签写入，并恢复测试前提示词、未提交生成任务。浏览器模拟不代表 Android 真机触摸与软键盘验收。
