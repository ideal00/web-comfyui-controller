# 自定义面板配色

右上角 **更多 → 面板配色**，或左侧 **界面 → 自定义面板配色**。Android 高级面板也使用这两个入口；刷新页面即可加载，无需更新 APK。

默认配色是柔和灰。可切换 **暖灰夜间、浅色鼠尾草、暖色纸张**；喜欢之前的界面，可选择 **原来的蓝色**。

下面五项可单独修改：**页面背景、卡片与弹窗、输入框、文字、强调色**。点击色块使用颜色选择器，或输入完整十六进制代码，例如 `#34302b`。完整有效的颜色立即生效并自动保存；文字与背景太接近时会提示调整。边框、次要文字和按钮底色自动跟随。

点击 **恢复柔和灰** 可以重置配色。关闭弹窗不会撤销已保存的颜色。配色只影响面板界面，不改变生成参数、模型、图片像素或画布内容。

设置保存在当前浏览器的网页数据中，刷新或退出再进入会保留。电脑、手机、不同浏览器，以及使用不同地址访问的页面分别保存；清除网页数据会恢复默认。浏览器禁止保存时，面板会说明当前颜色只临时生效。

弹窗会区分默认配色、已保存和保存不可用的状态，关闭再打开也会保留真实提示。保存数据损坏时恢复默认；修改有效颜色后可重新保存。
