# Easy Panel 2.3.1

修复手机高级面板“＋ 添加标签”候选区长时间空白或一直不显示的问题。配套 Android **1.4.7**，不需要安装新版 APK。

- 连续输入或中文输入法改变内容时，旧请求正常结束，后续查询不再卡住；同一查询只完成一次回调，避免旧结果覆盖新结果。
- 请求超时后保留可用来源；失败结果不永久缓存，可以继续重试。
- 添加标签弹窗显示搜索状态、候选数量与无匹配提示。
- 输入弹窗与候选列表根据手机可视区域定位，避开键盘和底部生成栏；关闭后移除定位监听，避免反复打开造成堆积。
- 更新前端资源缓存版本并同步安装包。

## 升级

已使用维护者当前本地目录的用户，在 Android 高级面板右上角刷新，或返回后重新打开即可加载网页修复。其他电脑下载 `EasyPanel-Core-OneClick.zip`，备份个人数据后安装、重启面板并刷新网页。ComfyUI 不需要因本次前端修复而重启。

附件提供七个安装包与 `SHA256SUMS.txt`，模型权重与个人数据不包含在内。

## 验证

新增连续输入、中文输入法、预设重复回调、超时重试与键盘可视区域回归测试；运行 JavaScript 回归，并检查安装器副本、ZIP 和 SHA256。浏览器中验证手机尺寸的英文连续输入、中文候选与缩小可视区域后的定位；未进行 Android 真机软键盘验收。
