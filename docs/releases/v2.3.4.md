# Easy Panel 2.3.4

为 LoRA 选择加入本地画风参考图，配套 Android **1.4.7**。

- 在“LoRA 与模型”展开“画风参考图”，按当前模型族、分类和搜索浏览；点击缩略图放大，按参考权重加入 LoRA。
- 选中已有 LoRA 时显示它的参考图和测试条件，同一模型不会重复加入。
- 参考图通过模型 SHA256 和 PNG 工作流核对绑定，持久副本与生成结果分开；原图同名保存到模型旁。
- 图片关联独立于提示词，编辑备忘会保留关联。个人图片和备忘不进入发布包。
- 安装包附带批量绑定工具；包含此前的手机数量恢复、快捷区展开、批任务控制和候选区修复。

## 升级

维护者当前本地页面已更新，在 Android 高级面板刷新即可加载，无需新版 APK。其他电脑下载 Core，备份个人数据后更新并刷新网页。参考图库来自个人已绑定的测试图，安装包不附带维护者的模型或测试图。

## 验证

230 项 JavaScript 回归测试与 5 项图片绑定测试通过；手机模式浏览器验证参考图筛选、图片加载、放大与 0.8 权重加入模型，未向生成队列提交任务。所有绑定均核对当前模型 SHA256 和 PNG 的实际测试条件；原有备忘字段不变。未进行 Android 真机验收。
