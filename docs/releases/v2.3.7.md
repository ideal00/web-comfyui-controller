# Easy Panel 2.3.7

修正页面跳转和工具遮挡，减少手机悬浮按钮占用，配套 Android **1.4.7**。

- 较窄的电脑窗口和手机点击“LoRA 与模型”时，直接滚动到模型资源栏。
- 从顶部导航切回提示词、生成设置、图片预览或模型区时，自动关闭高级工具层。
- 手机悬浮导航默认显示一个“☰”按钮，点击展开，选择入口或点击外部后收起；支持 Esc 和按住拖动。
- 透明抠图的标题与关闭按钮在滚动到下方参数、预览时仍保持可见。

## 更新

下载 Core，备份个人数据后更新。Android 继续使用 1.4.7，更新电脑面板后刷新高级面板即可。

## 验证

244 项 JavaScript 回归测试通过。使用示例数据的独立静态预览检查提示词、生成设置、图片预览、作品库、作品项目、手部修复、透明抠图与模型入口，验证 390px 手机及 1280px、1680px 桌面布局的资源栏跳转、工具关闭与快捷导航。未连接生产 ComfyUI，未提交生成任务，未进行 Android 真机验收。
