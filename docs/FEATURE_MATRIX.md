# 电脑与手机功能对照

配套版本：Easy Panel **2.3.6** / Android **1.4.7**。手机“高级面板”加载电脑上的同一网页；“快速生图”是独立的简化界面。

| 功能 | 电脑网页 | 手机快速页 | 手机高级面板 |
| --- | --- | --- | --- |
| 模型、提示词、尺寸、Seed 与常用生成 | 支持 | 支持 | 支持 |
| 中文描述转换 | 支持 | 支持 DeepSeek 指令与回答导入 | 支持 |
| 完整提示词分区、预设搜索、例图与锁定随机 | 支持 | 使用正向 / 负向简化表单 | 支持 |
| 创作游乐场 | 支持 | 使用高级面板 | 支持 |
| LoRA 备忘、OpenPose、多人区域与修复工具 | 支持，受模型 / 节点限制 | 使用高级面板 | 支持，受相同限制 |
| 作品库、收藏、翻页与原图查看 | 支持 | 支持 | 支持 |
| 恢复快照、换 Seed、继续编辑 | 支持 | 支持 | 支持 |
| 共享提示词预设与 LoRA 收藏 | 支持 | 完整管理使用高级面板 | 与电脑共用服务端数据 |
| 生成图片下载 | 浏览器下载 | Android Downloads | 原生 WebView 下载桥 |
| 编辑器草稿、折叠状态和游乐场偏好记录 | 当前浏览器保存 | 当前设备保存 | 当前 WebView 保存 |

恢复作品或修改提示词不自动生成，仍需确认并提交。不同设备必须连接同一个 Easy Panel 实例才能共享服务端内容。

模型限制以预检为准：当前 SDXL OpenPose ControlNet 与多人区域方案不适用于 Anima / Krea 2；Anima 高清重建内部包含 Anime6B 放大，因此与输出增强互斥。详细兼容性见 [主说明](../README.md#2-功能与模型兼容性)。
