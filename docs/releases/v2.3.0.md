# Easy Panel 2.3.0

本地新增功能与公开仓库、安装包和教程统一。本版配套 Android **mobile-v1.4.7**。

- 创作游乐场：自由组合、职业体验、性格演出、镜头卡、搭配检查、瘦身对照实验与审美盲选。
- 分区预设搜索、个人预设例图、词条 / 分区锁定随机，以及可视化词条上传与编辑。
- 桌面 / 手机作品库翻页、页码跳转与有界缩略图缓存；高级面板复用 Token 会话。
- 修复 Windows 作品索引迁移的 SQLite 连接未关闭问题。
- 完整快速开始、提示词教程、双端功能对照与自动发布流程；服务端代码报告的版本统一为 2.3.0。

## 下载

首次安装推荐 `EasyPanel-Core-OneClick.zip`，解压后双击 `安装-核心面板.cmd`。Pose、Color、Tags 可按需补装，All 包含全部模块安装入口；所有包均不包含模型权重或维护者个人图库。附件 SHA256 见 `SHA256SUMS.txt`。

## 升级

关闭面板，备份 LoRA 备注、共享状态、生成快照、队列、Token、个人例图 / 上传目录与外部图库。安装新版 Core，重启面板并刷新网页。手机快速页需要安装对应新版 APK；高级面板直接加载服务器的新网页。

## 验证范围

Python / Node 回归、前端资源与安装器副本一致性、七个 ZIP 内容及 SHA256 校验。Android 的独立测试与构建见手机 Release。未在本次发布中完成 Android 真机与真实 GPU 出图验收。
