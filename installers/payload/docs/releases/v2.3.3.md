# Easy Panel 2.3.3

修复手机高级面板重新进入后的生成数量、快捷工具自动收缩与批任务控制交互。配套 Android **1.4.7**，无需新版 APK。

- 生成数量独立保存并恢复；旧记录缺少数量或值异常时默认 1 张，明确保存的 16 张保留，与队列中每组任务的数量分开。
- 快捷工具仅为新挂载的折叠块恢复状态，队列刷新不会重置已展开区域；去掉状态文字更新引发的监听循环。
- 批任务控制与生成查重互不阻塞，请求 10 秒超时后可重试；操作期间防止重复提交，反馈显示在批任务区域。
- 旧刷新不能覆盖更新的操作结果；相同任务列表不重建，避免触摸目标被替换。
- 面板与教程明确“加入队列 → 发送队列 → 运行 / 暂停”的操作顺序，包含前两版候选搜索与点选修复。

## 升级

维护者当前本地目录已经更新，在 Android 高级面板右上角刷新，或返回后重新打开。首次升级旧记录时检查生成数量并设为需要的值，之后重新进入会恢复该数量。其他电脑下载 Core，备份个人数据后安装、重启面板并刷新网页。发布提供七个 ZIP 与 `SHA256SUMS.txt`。

## 验证

224 项 JavaScript 回归与 8 项 Python 队列测试通过。手机模式浏览器设置 3 张后重新进入仍为 3 张，批任务区域在多轮刷新后保持展开。任务控制的暂停、超时重试、旧刷新竞争与重复点击用模拟接口验证；未向生产队列提交生成、暂停或取消操作，未进行 Android 真机验收。
