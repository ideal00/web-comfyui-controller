混合图库按词条分类：如 `sword` 为其他补充，`holding_sword` 为姿势；`closed_eyes` 为表情，`blue_eyes` 为外貌，`eyepatch` 为服装配饰；`pastel_colors` 为画风上色，`backlighting` 为光线，`depth_of_field` 为构图。

身份设定按每个现有英文标签分别归类：海盗人物、海盗服饰和弯刀分别在人物、服装和其他补充框出现，共用原例图。没有现成英文身份标签的条目不创造身份词，搜索可找到其服饰、持物动作或道具组件。

图库页面可按“对应输入框”筛选；各框“搜索预设”、输入补全和随机同时读取个人预设及图库组件。自然语言和负面词不混入这些正向标签。其他补充框有独立骰子。分区随机保留锁定词条；单词随机显示被选词条的源例图。

新增图文词条或重建图库后会刷新搜索与随机来源。安装包同步此实现。

锁定一个词条后，随机会保留该词及原权重，从当前分区继续抽取其余内容；锁定词条旁的骰子用于保留它并随机下一个。整个分区锁定时仍禁止随机。分区例图默认收起，可用各框“显示例图 / 收起例图”或随机栏“例图：开启 / 关闭”控制；状态保存在当前浏览器，重新随机不会自动展开。
